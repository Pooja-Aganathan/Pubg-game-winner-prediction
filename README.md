# PUBG Game Winner Prediction

## Project Overview

This project focuses on predicting PUBG player win probability using machine learning regression techniques. The objective is to estimate player performance and identify gameplay factors that significantly influence winning probability.

The solution leverages gameplay statistics, feature engineering, and regression modeling to predict player placement percentage (`winPlacePerc`).

---

## Problem Statement

PUBG is a competitive multiplayer battle royale game where player performance depends on multiple gameplay factors.

The objective is to build a predictive machine learning model that estimates player win probability based on gameplay statistics.

---


## Dataset

The dataset contains player statistics such as:

- kills
- damageDealt
- walkDistance
- weaponsAcquired
- matchType

Target Variable:

- winPlacePerc
