# Models Directory

This folder stores trained machine learning model artifacts.

Models used in this project:

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- LightGBM Regressor

Model files such as:

- .pkl
- .joblib

can be stored here after training.

Trained model files are not uploaded to keep the repository lightweight.

Models can be regenerated locally using the notebook or training pipeline.
