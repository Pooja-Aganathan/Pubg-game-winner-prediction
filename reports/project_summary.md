# PUBG Game Winner Prediction – Project Summary

## Objective

Predict PUBG player winning placement percentage using gameplay statistics and machine learning regression models.

---

## Workflow

- Data preprocessing
- Exploratory Data Analysis
- Feature Engineering
- Feature Scaling
- Model Training
- Model Comparison
- Model Evaluation

---

## Models Used

- Linear Regression
- Random Forest Regressor
- XGBoost Regressor
- LightGBM Regressor

---

## Key Findings

- Walk distance strongly impacts winning percentage
- Damage dealt contributes significantly to performance
- Combat efficiency affects player ranking
- Feature engineering improved prediction capability

---

## Business Impact

This project demonstrates gaming analytics applications using machine learning for:

- Player behavior analysis
- Gameplay optimization
- Performance prediction
- Gaming analytics insights

---

## Conclusion

Machine learning regression models successfully predicted PUBG winning placement percentage using gameplay statistics and engineered features.
